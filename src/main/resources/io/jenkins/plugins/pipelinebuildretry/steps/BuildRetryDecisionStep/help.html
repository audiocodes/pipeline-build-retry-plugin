Decides now, with the build's current result, whether this build would be retried, and returns the decision as a map: willRetry, wouldRetry, reason, result, abortKind, retryCount, nextRetryCount, maxSchedule, delaySeconds (null when no retry is planned), neverRetryPattern (the number of the never-retry pattern that stopped the retry, or null) and more. Use it in post to word a notification ("will retry" or "failed for good").

The decision is recorded on the build. When the build ends with the same result, and no point of no return was passed since, the recorded decision is used as it is, so the notification and the retry always agree. When the result changed, the plugin decides again and logs why.

The step takes no options: it uses the job's buildRetry option. On a job without it, it returns willRetry: false with reason not-configured and records nothing.
