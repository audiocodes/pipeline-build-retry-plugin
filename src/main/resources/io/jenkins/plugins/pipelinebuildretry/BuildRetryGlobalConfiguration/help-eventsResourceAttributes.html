Extra resource attributes sent with every event, as key=value entries, one per line or separated by commas, for example deployment.environment.name=prod. Values cannot contain commas. At most 20 entries are sent.

They can replace the defaults service.namespace (jenkins) and jenkins.url; service.name is set by Events service name and is ignored here. Loki turns some well-known resource attributes, such as deployment.environment.name, into indexed labels and the rest into structured metadata, with dots turned into underscores (deployment_environment_name); keep label values few, such as one per environment, never per build.
