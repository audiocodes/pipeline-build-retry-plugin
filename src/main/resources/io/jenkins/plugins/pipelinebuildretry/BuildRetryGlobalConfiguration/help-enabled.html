On by default. Turn it off to stop every retry on this controller at once, without a restart: when a build with buildRetry ends, the plugin scans nothing, decides nothing and queues nothing, and the build log says [Build Retry] retries are turned off on this controller. buildRetryDecision() returns willRetry: false with reason disabled.

To turn it off, an administrator runs this line in the script console (Manage Jenkins → Script Console):

io.jenkins.plugins.pipelinebuildretry.BuildRetryGlobalConfiguration.get().setEnabled(false)

io.jenkins.plugins.pipelinebuildretry.BuildRetryGlobalConfiguration.get().setEnabled(true) turns retries back on. The line saves only this plugin's settings file. Unticking this box and saving the page also works, but saving this page saves every setting on it again.

Retries already waiting in the queue are left as they are; cancel them in the queue if needed. Under abortPrevious, a newer build still cancels a waiting retry. Turning the switch back on applies from the next build that ends.
