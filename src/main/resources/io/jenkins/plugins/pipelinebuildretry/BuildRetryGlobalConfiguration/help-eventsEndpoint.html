The collector's OTLP/HTTP address, such as https://collector:4318; /v1/logs is added unless the address already ends with it. Blank sends nothing. The collector's certificate must be trusted by the controller's Java runtime. With an events token set, use https unless the collector is on a loopback address.

While the collector cannot be reached, events are dropped and each failed batch logs one Failed to export logs warning. The plugin lowers that OpenTelemetry exporter logger's SEVERE records to warnings without a stack trace, for every plugin that shares it.
