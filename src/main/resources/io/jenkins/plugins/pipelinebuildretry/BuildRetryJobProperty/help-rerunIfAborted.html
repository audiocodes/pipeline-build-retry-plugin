Which aborted builds to retry, by what aborted them, read from the flow graph:

  • never (default, as in the freestyle plugin)
  • infra: the agent went away (removed node, closed channel, a deleted or evicted pod)
  • timeout: a timeout step expired
  • infraOrTimeout
  • always: also a person pressing Stop, and aborts with no evidence

A build the Gerrit Trigger plugin aborted for a new patch set or an abandoned change is never retried, not even with always. A person pressing Stop is never infra. A Kubernetes pod whose containers ended only OOMKilled, Completed or DeadlineExceeded is not agent loss.
