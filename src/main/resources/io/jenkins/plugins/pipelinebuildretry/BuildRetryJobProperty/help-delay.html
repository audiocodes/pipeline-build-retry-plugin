How long the retry waits in the queue, counted from the end of the failed build. The default is progressive with increment 300 and maximum 10800 seconds, as in the freestyle plugin: 300, 900, 1800, 3000, … seconds.

  • fixedDelay(60): the same delay every time.
  • progressiveDelay(increment: 300, max: 10800): increment × (n+1)(n+2)/2 before retry n+1, capped at max; max 0 means no cap.
  • listDelay(seconds: [30, 90, 180]): one value per retry; the last repeats.
